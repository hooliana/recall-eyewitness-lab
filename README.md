# RECALL — Eyewitness Memory Lab

RECALL is an interactive web experiment exploring eyewitness memory, leading-question effects, recall accuracy, and confidence.

Participants watch a short simulated incident, answer a randomized series of memory questions, receive a confidence score, and are randomly assigned to either a neutral or leading-question condition.

## Features

- Timed CCTV-style incident sequence
- Randomized experimental conditions
- Shuffled answer choices
- Eyewitness recall questions
- Confidence rating
- Automatic scoring
- Anonymous response collection with Supabase
- Live aggregate results dashboard
- Responsive interface

## Built With

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Purpose

This project was created as an independent criminal justice × psychology × web development project focused on how question wording and confidence can relate to eyewitness recall.

## Note

RECALL is an educational interactive demonstration, not a formal academic study.
